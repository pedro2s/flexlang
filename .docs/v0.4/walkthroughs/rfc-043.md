# Walkthrough — RFC-043: Projeto de Homologação "FlexBank Distributed Ecosystem"

## 1. Visão Geral e Contexto

A **RFC-043** consolida a validação enterprise de ponta a ponta da **FlexLang v0.4.0**, integrando todas as capacidades construídas entre as RFCs 031 e 045 em uma arquitetura distribuída composta por 3 microsserviços reais comunicando-se via HTTP síncrono e Mensageria de Eventos assíncrona com telemetria W3C, ledger financeiro de precisão arbitrária, idempotência e observabilidade completa.

```
+---------------------+          HTTP Client (mTLS)          +--------------------------+
| flexbank-core       | -----------------------------------> | flexbank-pix-gateway     |
| - JWT Auth (RS256)  |                                      | - BACEN SPI Integration  |
| - Regex Validation  |                                      | - Circuit Breaker        |
| - Decimal Ledger    |                                      | - Idempotency Key Engine |
| - OpenTelemetry     |                                      | - Counter Metrics        |
+---------------------+                                      +--------------------------+
          |                                                               |
          |                     Kafka / Event Stream                      |
          +---------------------------------------------------------------+
                                          |
                                          v
                              +--------------------------+
                              | flexbank-audit-notifier  |
                              | - Async Settle Consumer  |
                              | - Signed Audit Log (fs)  |
                              | - Prometheus Metrics     |
                              | - Cron Reconciliation    |
                              +--------------------------+
```

## 2. Microsserviços Construídos (`examples/10_flexbank_distributed/`)

### 2.1. `flexbank-core`
- **Responsabilidade**: Serviço central de autenticação e transferências bancárias.
- **Recursos Validados**:
  - Geração de tokens JWT autenticados (`crypto/jwt`).
  - Validação de chaves Pix com Expressões Regulares (`std/regex`).
  - Aritmética financeira exata via `Decimal` (`math/decimal`).
  - Rastreamento distribuído com Spans OpenTelemetry (`core/telemetry`).
  - Publicação de eventos de liquidação via `Producer` (`mq/kafka`).

### 2.2. `flexbank-pix-gateway`
- **Responsabilidade**: Gateway de liquidação SPI (BACEN) com proteção contra falhas e requisições duplicadas.
- **Recursos Validados**:
  - Proteção e fallback via `CircuitBreaker` (`core/resilience`).
  - Deduplicação atômica de requisições com locks e cache em memória via `IdempotencyEngine` (`finance/idempotency`).
  - Contadores de requisições e métricas de tráfego (`core/telemetry`).

### 2.3. `flexbank-audit-notifier`
- **Responsabilidade**: Auditoria contábil, integridade criptográfica e fechamento diário.
- **Recursos Validados**:
  - Consumo assíncrono de eventos com `Consumer` (`mq/kafka`).
  - Assinatura criptográfica SHA-256 codificada em Base64 (`crypto`, `encoding/base64`).
  - Gravação em arquivo de log no sistema de arquivos (`std/fs`).
  - Endpoint de métricas em formato padrão Prometheus (`/metrics`).
  - Agendamento cron determinístico de conciliação noturna (`core/scheduler`).

## 3. Teste de Integração Enterprise (`tests/flexbank_distributed_integration.ts`)

Desenvolvido um orquestrador automatizado em TypeScript (`npx tsx tests/flexbank_distributed_integration.ts`) que:
1. Sobe simultaneamente os 3 microsserviços em portas isoladas (9881, 9882, 9883).
2. Valida o fluxo completo no **Modo Interpretado** (Node.js).
3. Transpila cada microsserviço para Go, compila em binários nativos executáveis e repete o fluxo no **Modo Compilado** (Golang).
4. Verifica 100% de paridade comportamental (ADR-001) em todos os cenários:
   - Healthcheck simultâneo dos 3 serviços (`/healthz`).
   - Autenticação e emissão de token JWT válido (`POST /auth/login`).
   - Validação de formato Regex e débito no Ledger Decimal com subtração exata (`POST /pix/transfer`).
   - Processamento de primeira viagem com Idempotency Key (`POST /spi/process`).
   - Reenvio idêntico retornando resposta em cache sem novo processamento.
   - Extração de métricas Prometheus textuais (`GET /metrics`).
