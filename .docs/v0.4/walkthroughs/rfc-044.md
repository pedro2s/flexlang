# Walkthrough — RFC-044: Expressões Regulares Nativas (`std/regex`)

## Resumo da Implementação

A **RFC-044** introduziu o módulo nativo de expressões regulares (`std/regex`) na FlexLang, permitindo compilação segura prévia, validação, extração de padrões e substituição de strings com garantia de proteção contra *ReDoS* (complexidade linear $O(n)$ via motor RE2 em Go) e paridade estrita (ADR-001) entre o modo interpretado e compilado.

---

## Recursos Implementados

### 1. Namespace e Compilação (`regex`)
- **`regex.compile(pattern: String) -> Result<Regex, String>`**:
  - Compila previamente a expressão regular, validando a sintaxe em tempo de inicialização.
- **`regex.is_match(pattern: String, text: String) -> Result<Bool, String>`**:
  - Atalho utilitário para validação direta de correspondência.

### 2. Métodos de Instância (`Regex`)
- **`matches(text: String) -> Bool`**:
  - Testa se o texto contém correspondência com o padrão.
- **`find(text: String) -> Option<MatchResult>`**:
  - Localiza o primeiro match no texto, retornando `Option.Some(MatchResult)` com `text`, `start` e `end`.
- **`find_all(text: String) -> Array<MatchResult>`**:
  - Retorna uma lista de todas as ocorrências encontradas no texto.
- **`replace_all(text: String, repl: String) -> String`**:
  - Substitui todas as correspondências do padrão pela string informada.
- **`split(text: String) -> Array<String>`**:
  - Divide a string utilizando a expressão regular como delimitador.

### 3. Estrutura `MatchResult`
- **`text: String`**: Substring correspondente encontrada.
- **`start: Int`**: Índice inicial (0-indexed).
- **`end: Int`**: Índice final (0-indexed).
