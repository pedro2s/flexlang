# Walkthrough: RFC-046 — Suporte a Multipart/Form-Data e Upload de Arquivos no Servidor HTTP (`net/http`)

## Resumo da Implementação

Implementamos a **RFC-046**, adicionando suporte completo a formulários `multipart/form-data` e `application/x-www-form-urlencoded` no servidor HTTP (`net/http: Server` e objeto `Request`), com **100% de paridade entre o interpretador Node.js/TypeScript e o transpilador nativo Golang (ADR-001)**.

---

## 1. Modificações Efetuadas

### 📦 Core Engine (`src/modules/http.ts`)
- **Estrutura `UploadedFile`:**
  - Registrada em `types` e `runtimeBinding`:
    ```flexlang
    struct UploadedFile {
        filename: String,
        content_type: String,
        size: Int,
        content: String
    }
    ```
- **Novos Métodos em `Request`:**
  - `req.form_value(name: String) -> Option<String>`
  - `req.form_file(name: String) -> Option<UploadedFile>`
- **Runtime Interpretado (Node.js):**
  - Implementadas as funções `parseMultipartBuffer` (decodificação de boundaries MIME) e `parseUrlEncodedBody`.
  - Adicionado lazy-parsing em `FlexRequest.ensureFormParsed()` para decodificar campos e arquivos sob demanda.
- **Boilerplate Go (`GO_BOILERPLATE`):**
  - Definida struct `UploadedFile` com campos exportados.
  - Adicionado campo `rawRequest *http.Request` ao struct `Request` do Go.
  - Implementado `(r Request) form_value(name string) Option` integrando com `r.rawRequest.FormValue`.
  - Implementado `(r Request) form_file(name string) Option` lendo arquivos de `r.rawRequest.MultipartForm.File`.
  - `dispatch` em Go preserva o stream do corpo via `r.Body = io.NopCloser(bytes.NewReader(body))`.

### 📚 Documentação de Referência (`reference/`)
- Atualizados `reference/src/content/docs/stdlib/http.md` (pt-BR) e `reference/src/content/docs/en/stdlib/http.md` (en) com a tabela de métodos do `Request`, a definição da struct `UploadedFile` e exemplos completos de rotas de upload de arquivos.

### 🎨 Ferramentas do VSCode (`editors/vscode/`)
- **TextMate Grammar (`syntaxes/flexlang.tmLanguage.json`):** Adicionado `UploadedFile` na lista de classes da biblioteca padrão.
- **LSP Server (`src/server/server.ts`):** Atualizada a documentação de `Request`, adicionado `UploadedFile` e `MultipartForm` aos autocompletions e hovers.
- **Snippets (`snippets/flexlang.json`):** Adicionado snippet `HTTP Multipart Upload Handler` (`http-upload`).
- **Testes (`tests/syntax.test.ts`):** Adicionada seção 31 testando o TypeChecker com `UploadedFile`, `form_value` e `form_file`.
